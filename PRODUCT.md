# ORCA

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

An integrated workspace for projects, documents, visual boards, tasks and calendars.

## Operating Context

Home is the first page after sign-in. Users need to see today's work quickly without starting or completing focus sessions. Daily includes open tasks planned for today, due today, or linked to a calendar session today.

## Capabilities and Constraints

The dashboard is customizable through widgets. Daily tasks and unscheduled tasks are independent widgets. Ordinary dashboard rows open details; they do not have Start or Complete controls. Preserve existing project, calendar and capture workflows. Initial layout preferences are browser-local and scoped to user and workspace; cross-device synchronization is not included.

## Product Principles

- Show essential task information first and details on demand.
- Keep customization controls out of the everyday view.
- Use existing task and event data rather than duplicate task state.
